# 2–3 Minute Demonstration Guide

Use this outline when recording your screen or presenting live:

1. **0:00–0:20 — Introduction:** State the project title and explain that parents can track buses while administrators manage routes and schedules.
2. **0:20–0:45 — Login and roles:** Sign in as admin and show the dashboard.
3. **0:45–1:20 — Administration:** Show creating a bus, route and trip. Briefly show editing a bus or route and the user list.
4. **1:20–1:45 — Driver GPS:** Sign in as a driver, select an active trip and start sharing the current location (allow browser permission).
5. **1:45–2:20 — Parent tracking:** Sign in as a parent, show the map, trip details and search feature.
6. **2:20–2:45 — Technical requirements:** Briefly show `database/schema.sql`, `database/seed.sql`, `TEST_PLAN.md` and explain password hashing, prepared statements, CSRF tokens and the JSON API.

Do not show real student names, phone numbers, or private location information in the recording. Use demonstration accounts and test data.
